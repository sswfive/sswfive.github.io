Agent

agentic-design-patterns

  • 谷歌新书 Agent 设计模式中文版，持续更新，提供在线阅读、PDF 和 EPUB 电子书下载。

深入理解 AI Agent：设计原理与工程实践

  • 本书的核心公式：Agent = LLM + 上下文 + 工具，三者缺一不可。

Rust 学习

Rust Tutorial

  • 面向新手的 Rust 快速教程，从零实现一个用于记录 Todo 事项的 CLI 程序。

Rust 语言实战

  • 通过有挑战性的示例、练习题和实践项目提升 Rust 水平，建立从入门到实战的直通桥梁。

数据结构与算法

labuladong 的算法笔记

  • 框架化、模块化的算法解题思维，60 多篇基于 LeetCode 的原创文章，涵盖所有题型和技巧。

Hello 算法

  • 动态图解、一键运行的数据结构与算法教程，支持 Python、Java、C++、Go、Rust、TS 等十余种语言。

算法通关手册

  • 从零开始的算法与数据结构学习教程，含 200 道面试热门题目和 1000+ 道 LeetCode 题目解析。

代码随想录

  • LeetCode 刷题攻略：200 道经典题目刷题顺序，60 万字详细图解，50 余张思维导图，支持多语言版本。

数据结构和算法必知必会的 50 个代码实现

  • 王争：数据结构和算法必知必会的 50 个代码实现。

Data Structure Visualizations

  • 以可视化方式讲解数据结构和算法的运行过程。

python_data_structures_and_algorithms

  • Python 中文数据结构和算法教程。

Play-with-Algorithms

  • 慕课网课程《算法与数据结构精解》的官方代码仓。

算法刷题站点

labuladong 的题目列表

  • labuladong 整理的 LeetCode 刷题顺序清单。

CodeTop

  • 面试高频算法题库，按岗位和公司聚合刷题。

机器学习

Pytorch 实用教程

  • 《Pytorch 实用教程》（第二版），覆盖零基础入门、CV/NLP/LLM 项目应用和工程化部署。

Datawhale

  • 专注于 AI 领域的开源学习组织，产出机器学习、深度学习、编程和数学等内容。

ml-system-design-pattern

  • 机器学习系统设计模式：涵盖训练、服务化和操作的生产环境系统设计。

大模型

大语言模型

  • 人民大学 AI Box 小组编写的开放电子书，适用于有深度学习基础的高年级本科生和研究生。

Happy-LLM

  • 从零开始的大语言模型原理与实践教程，从 NLP 研究方法出发逐层剖析 LLM 的架构与训练。

提示词工程

  • 关于提示工程、上下文工程、RAG 以及 AI 代理的指南、论文、课程和资源合集。

软件架构

深入高可用架构原理与实践

  • 开源架构设计书籍，聚焦网络、集群及服务治理、FinOps 三大主题。

云原生

Kubernetes 基础教程

  • 全面介绍容器编排技术的实战手册，涵盖容器、Kubernetes、服务网格、Serverless 等领域。

Go 学习

Easy 搞定 Golang 设计模式

  • 一份 Golang 设计模式教程。

Go 微服务实践

  • 关于 Go 微服务架构与事务处理的博客文章。

Go Leetcode

  • Go 语言的 LeetCode 刷题笔记。

地鼠文档

  • Go 语言中文文档聚合站，方便检索官方库与常用包。

前端学习

introduction-to-front-end-engineering

  • 一本小书《带你入门前端工程》。

印记中文

  • 前端技术文档中文翻译聚合网站。

数据库

SQL 之母

  • 在线 SQL 学习网站。

mysql-tutorial

  • MySQL 系列教程。

正则表达式

《学习正则表达式，从零基础到高阶》

  • 系统性的正则表达式中文学习教程，从基础到高阶逐层讲解。

分布式算法

Raft 分布式共识算法动画演示

  • 以动画方式直观演示 Raft 共识算法的选主、日志复制等核心流程。

TypeWords

  • 网页端背单词软件，内置 CET-4/6、GMAT、GRE、IELTS 等词库，另有程序员常用词汇和编程语言 API 词库。
