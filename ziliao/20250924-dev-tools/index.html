编程开发工具与解决方案

Agent 相关

关于 Agent Skills 的甄选清单与发现渠道，见 甄选清单之 Skills。

MCP

MCPJungle

  • 开源可自托管的 MCP 网关，统一管理所有 MCP 服务器。

智能问数

SQLBot

  • 基于大语言模型和 RAG 的智能问数系统，DataEase 开源，支持对话式数据分析和可视化图表生成。

编程与 AI 工具

JetBrains

  • IDE 全家桶。

Visual Studio Code

  • 微软出品的开源代码编辑器。

Cursor

  • AI 辅助编程工具。

Zed

  • 面向高性能人机及 AI 协作的新一代代码编辑器。

TRAE

  • 字节开发的 AI 编程 IDE。

AI 相关技术

Awesome-MCP-ZH

  • 面向中文用户的 MCP 资源合集，含基础介绍、玩法、客户端、服务器和社区资源。

AI 迷思录

  • 从零培养 AI 安全实战能力，覆盖基础知识、法律法规、经典模型、漏洞与防御、安全开发与运维等。

开源解决方案

GPU 相关

HAMi

  • 异构 AI 计算虚拟化中间件（Heterogeneous AI Computing Virtualization Middleware），前身为 k8s-vGPU-scheduler，帮助在 Kubernetes 工作负载间共享 GPU 及其他 AI 加速器，隔离设备显存和算力，无需修改应用代码。

存储方案

CubeFS

  • 新一代云原生分布式存储系统，支持 S3、HDFS 和 POSIX 等访问协议，适用于大数据、AI、容器平台、数据库等场景。

任务调度

SnailJob

  • 灵活、可靠且高效的分布式任务重试和任务调度平台（Java 开发）。

可观测性

OpenObserve

  • 云原生可观测性平台，专为日志、指标、跟踪、分析和 RUM 构建，设计用于 PB 级工作，可作 ELK 的替代品。

开源书签

  • 分门别类整理的常见热门开源组件，涵盖接入层、数据库、消息中间件、大数据、K8S、监控等。

在线代码编辑器

code-server

  • VS Code in the browser，支持多种插件，可自托管以实现完全安全性和控制。

monaco-editor

  • 基于浏览器的在线代码编辑器。

Redis 客户端工具

Tiny RDM

  • 优秀的 Redis 可视化管理工具，支持多种连接方式、分段加载、慢日志、转码显示，跨 Windows、Linux、macOS。

RedisShake

  • Redis 数据处理和迁移工具。

redis-manager

  • Redis 一站式管理平台，支持集群监控、安装、管理、告警及基本数据操作。

正则测试工具

regex101

  • 在线正则表达式测试与调试工具，支持多种编程语言正则方言。

API 管理工具

Yaak

  • 快速、注重隐私的 API 客户端，支持 REST、GraphQL、SSE、WebSocket 和 gRPC，基于 Tauri、Rust 和 React 构建。

Postman

  • 老牌 API 设计、开发与测试平台。

Apifox

  • 集 API 文档、调试、Mock、测试于一体的接口协作平台。

Restfox

  • 在线 API 测试工具，Postman 替代品。

Posting

  • 终端中的 API 测试工具。

格式转换工具

json-server

  • 小巧的接口模拟工具，创建 JSON 文件后一条命令即可启动接口服务。

Json Editor

  • 基于 Web 的 JSON 编辑器，支持树形、代码和纯文本模式，可在线使用或集成到项目中。

ConvertSimple

  • Json、YAML、TOML 之间的在线转换工具。

transform

  • 多语言网络转换器。

JsonFormatter

  • 在线 JSON 格式化工具。

docker-compose 工具集

docker-compose

  • 通过 docker-compose 编排一键快速部署常见数据库、消息队列、日志系统、CICD、存储系统等环境。

kafka-stack-docker-compose

  • 使用 docker-compose 一键创建 Kafka 服务，支持单节点和集群创建。

kafka-ui

  • 用于管理 Apache Kafka 集群的多功能、快速且轻量级的 Web UI。

SSL 证书管理

AllinSSL

  • 一站式 SSL 证书全生命周期管理工具，支持申请、签发、部署、续期与监控，全面覆盖主流 CA。

Certd

  • 开源 SSL 证书管理工具，全自动申请、更新、续期，支持通配符证书，可自动化部署到阿里云、腾讯云、主机等。

Nginx 相关

nginx-flow

  • 功能强大的 Nginx 配置文件可视化编辑工具。

nginx-proxy-manager

  • 用于管理 Nginx 代理主机的 Docker 容器，提供简单而强大的界面。

nginxconfig

  • Nginx 配置生成器，支持多种编程语言场景。

向量数据库

seekdb

  • 开箱即用的轻量级向量数据库，OceanBase 团队开源，支持关系型、向量和文本数据的统一存储与检索，最低 1C1G 即可运行，兼容 MySQL 协议。

K8S 相关

Kite

  • 开源轻量级 K8s 管理面板，支持查看 Pod 日志、执行容器命令、编辑 YAML 配置、管理用户权限等。

kdash

  • 用 Rust 构建的简单 Kubernetes 终端仪表盘。

KubeVPN

  • 基于云原生的开发环境，能够连接到 Kubernetes 集群网络。

其他

LazyTyper

  • 基于 Whisper 的免费语音输入应用，准确率高达 90%，支持中英日韩等多语言无缝混合输入。

代码托管工具

Gogs

  • 简单、稳定且可扩展的自托管 Git 服务，Go 语言实现，以独立二进制分发包形式部署。

Codeberg

  • 基于 Git 的开源代码托管平台，提供免费、开放且隐私友好的协作环境，强调非营利和社区驱动。

Forgejo

  • 自托管轻量级软件仓库，安装简便，维护成本低。
