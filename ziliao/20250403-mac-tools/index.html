实用清单

MacTools

  • 免费开源的 macOS 菜单栏工具集合，集成防休眠、自动隐藏 Dock、系统静音、Xcode 清理、IP 查询和翻译等功能。

uTools

  • 跨平台效率工具平台，支持 Win/MacOS/Linux，是 Alfred 的替代品，拥有丰富的插件库。

Alfred

  • 专注 MacOS 的效率工具，被 uTools 取代。

MessAuto

  • 自动提取 Mac 平台短信和邮箱验证码的工具。

Dropover

  • macOS 效率工具，通过可暂存文件的”篮子”优化拖拽操作，便于批量管理文件、图片或链接。

pear-rec

  • 跨平台的截图、录屏、录音、录像软件。

ScrollSnap

  • Mac 滚动截图工具，解决 macOS 原生截图不支持滚动截图的问题。

EcoPaste

  • 跨平台剪贴板管理工具。

MacCalendar

  • 完全免费&开源的 macOS 菜单栏日历 App，支持中国农历、节假日、放假安排、系统日程等。

AppPorts

  • 无缝迁移应用到外部存储并自动建立连接，释放宝贵的本地空间。

WailBrew

  • Homebrew 可视化工具，提供简洁的图形界面管理软件包。

Mole

  • 像鼹鼠一样深入挖掘来清理你的 Mac。

Tidy Up

  • Mac 上优秀的重复文件搜索和清理工具，支持指定目标目录和文件类型。

AirBattery

  • 在 Mac 上获取所有设备的电量信息并显示在 Dock / 状态栏 / 小组件上。

Tuxera

  • Microsoft NTFS for Mac，在 Windows 和 Mac 之间无缝读写 NTFS 存储设备，可靠性更佳。

Nigate

  • 开源 NTFS 读写解决方案，专为 Apple Silicon 优化，支持 NTFS 驱动器的读写访问、挂载和管理。

IINA

  • 强大的 macOS 视频播放器，界面简洁美观，契合 macOS 设计风格，支持在线字幕、缩略图预览、画中画等。

常用快捷键：

操作 含义
⌘ + N 新建窗口
⌘ + T 新建 Tab
⌘ + W 关闭 Tab / 窗口
⌘ + ← 切换到上一个 Tab
⌘ + → 切换到下一个 Tab
⌘ + 数字 快速切换 Tab
⌘ + D 垂直分屏
⌘ + Shift + D 水平分屏
⌘ + Enter 切换全屏
⌘ + F 查找
⌘ + / 查看光标的位置
Ctrl + P 上一条命令
Ctrl + R 搜索命令历史
Ctrl + L 清屏
Ctrl + U 清除当前行
Ctrl + W 删除光标前面的一个单词
Ctrl + K 删除光标后面的所有字符
Ctrl + A 移动光标到行首
Ctrl + E 移动光标到行尾
