甄选实用 & 效率工具

在日常工作和学习中，好的工具能让效率提升不止一个档次。这是我收集整理的一份实用工具清单。本甄选合集将持续更新……🚀

Markdown 编辑器

FlyMD

  • 轻量级、高性能的本地 Markdown 编辑器，支持 PDF 高精度解析、AI 辅助写作、智能待办提醒等功能。

UI 相关

storyset

  • 免费插画网站，提供可自定义的动画和静态插画素材。

菜鸟图标

  • 免费商用矢量图标库，含 20 万+ 高品质矢量图标。

Icons8

  • 原创图片库，提供免费图标、剪贴画插图、照片和音乐，是创作人员和开发者的终极设计套件。

Emoji copy

  • Emoji 图集网站，支持一键复制。

Emoji 大全

  • 最新、完整的 Emoji 搜索和信息平台，含表情符号含义、Unicode 代码点、矢量图形等。

favicon.io

  • 网站图标 Favicon 的在线生成工具。

Axure 地图元件库

  • 可一键复制省/市/区 SVG 地图元件。

Vue Color Avatar

  • 纯前端的矢量风格头像生成网站，可搭配不同素材组件生成个性化头像。

画图相关

mind-map

  • 功能强大的 Web 思维导图工具。

Frame0

  • 在线草图绘制工具。

Pddon

  • 免费多功能专业在线画图工具，提供低代码和 AI 智能辅助。

Mermaid

  • 基于 JavaScript 的图表绘制工具，使用 Markdown 启发的文本定义来创建和修改复杂图表。

Pointless

  • 开源网页画板，可当作白板使用。

Drawio

  • 在线流程图绘制网站，支持多种图表类型。

Excalidraw

  • 简单易用的白板绘图开源工具，手绘风格，支持无限画布。

Drawnix

  • 开源开箱即用的白板工具，包含思维导图、流程图、自由画等功能。

PDF 相关

章快图

  • 免费在线 PDF 盖章工具，支持添加普通印章和骑缝章。

Stirling-PDF

  • 基于 Docker 的本地托管 PDF 操作工具，支持拆分、合并、转换、添加图像、旋转、压缩等操作。

图片相关

PicView

  • 比系统自带更好用的看图工具，支持 Windows 和 macOS，体积小、启动速度快，支持长图浏览和格式转换。

upscayl

  • AI 提升图片清晰度的软件，支持 Linux、Mac、Windows 多平台。

carbon

  • 免费代码贴图工具，将代码生成为美观的图片。

Drawl.ink

  • 在线将链接转化为美观图片的工具。

照片转手绘

  • AI 工具，将照片转换为铅笔素描、炭笔画、水彩和卡通效果等艺术画作。

文字相关

calligrapher.ai

  • 在线工具，将英文输入变为手写体并带有动画效果，支持 SVG 格式下载。

文字转手写

  • 免费在线工具，将数字文字转换为漂亮的手写笔记，支持多种纸张背景。

翻译相关

沉浸式翻译

  • 全网口碑炸裂的双语对照网页翻译插件，支持 PDF 翻译、EPUB 电子书翻译、视频双语字幕翻译等，可调用 DeepL、Gemini 等 AI 引擎。

电子书阅读器

Koodo-reader

  • 跨平台的现代电子书管理器和阅读器，支持多端同步和备份。

Ebook-reader

  • 在线电子书阅读器，支持像 Yomitan 这样的词典扩展。

Flow

  • 开源的基于浏览器端的 ePub 阅读器。

任务管理

Super Productivity

  • 跨平台待办事项列表应用，集成 Timeboxing 和时间跟踪功能，支持与 Jira、GitHub、GitLab 等集成。

DooTask

  • 轻量级开源在线项目任务管理工具，提供文档协作、在线思维导图、流程图、任务分发等功能。

focalboard

  • 开源、多语言、自托管的项目管理工具，兼容 Trello 和 Notion 特点，支持看板、表格和日历视图。

简历相关

LapisCV

  • 开箱即用的简历模板，基于 Markdown 格式，支持 Obsidian 和 Typora，可直接导出 PDF。

热速美斯

  • 免费简历制作网站，支持自由拖拽，帮助制作精美简历。

打字练习站点

Code Typing Script

  • 代码打字速度测试，可选择不同的编程语言。

10 Fast Fingers

  • 在线输入速度测试网站。

Qwerty

  • 在线打字练习网站。

蓝豆打字

  • 在线打字练习网站，渐进式、智能辅助、强化记忆。

keybr

  • 根据输入错误定向训练，通过非真实单词分析输入薄弱环节。

typing.io

  • 编程打字练习网站，通过编程练习训练输入效率。

codeflow

  • 开源在线指法练习网站，提供关键字、单词、词组、句子、标点的指法练习。

typelit.io

  • 通过打小说来练习打字。

typingclub

  • 系统学习打字的在线平台。

检测工具

Setup Check

  • 无广告的在线检测工具，可测试网速、耳机、麦克风、鼠标键盘、摄像头等。

All in SSL

  • 集证书申请、管理、部署和监控于一体的 SSL 证书全生命周期管理工具。

公众号排版工具

bm.md

  • 好用的 Markdown 排版助手，一键适配微信公众号、网页和图片。

WeMD

  • 优雅的 Markdown 公众号排版工具，Markdown 写作一键复制到公众号，本地优先编辑器。

花生公众号排版器

  • 专为微信公众号设计的 Markdown 编辑器。

文颜

  • Markdown 文章排版美化工具，支持微信公众号、今日头条、知乎等平台。

RSS 阅读器

MrRSS

  • 现代化、跨平台的 RSS 阅读器。

Folo

  • AI RSS 阅读器。
