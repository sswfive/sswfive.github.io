Windows实用工具与资源汇总

本系列持续更新中……🚀

软件下载源

果核剥壳

  • 果核剥壳，还原软件的本质。信息爆炸的时代，纷杂的互联网，我要做的就是把绿化的，修改的绿色软件分享给大家。

实用清单

装个机：装机工具

  • 专业为普通用户打造的电脑重装系统指南教程网站，提 供Windows 重装系统教程、macOS 重装系统指南、一键重装系统工具、U 盘启动盘制作方法，让系统重装变得简单快捷。

命令行激活：Windows/Office激活

MAS：Windows/Office激活

  • 全称：Microsoft-Activation-Scripts，使用HWID/Ohook/KMS38/在线KMS激活方法的 Windows 和 Office 激活工具，注重开源代码和较少的杀毒软件检测； 官网：点击前往

KMS.CX：Windows/Office激活

  • 一款一键激活 windows/office的工具；立即体验：点击前往

WindowsCleaner：系统清理

  • 专治 C 盘爆红及各种不服！专业清理系统垃圾，让系统始终保持最佳运行状态。无需注册登录即可使用，并且无任何广告。

ZyperWinOptimize:Windows优化工具

  • ZyperWin++是一个轻便的windows优化工具，适用于Win7-Win11最新版的优化，包括性能优化、服务项优化、垃圾清理等操作，还支持系统激活和Office快速安装。

阅读器

Koodo Reader：电子书阅读器

  • 一款现代电子书管理器和阅读器，具有适用于 Windows、macOS、Linux 和 Web 的同步和备份功能
  • Github | 下载

Sumatra PDF：PDF阅读器

  • 一款适用于 Windows 的免费PDF、EPUB、MOBI、CHM、XPS、DjVu、CBZ 和 CBR阅读器。体积小、速度快、可自定义且功能齐全
  • 下载

系统工具

Office Tool Plus：Office部署激活

  • 一个用于部署、激活 Office、Visio、Project 的强大工具
  • Github

Dism++：系统优化工具

  • 基于 Windows 系统原生功能 Dism 开发的增强工具，体积小，解压即用
  • 集成空间清理、系统管理/优化、热备份还原等功能于一体
  • Github

WPD：隐私优化

  • 隐私管理、预装应用卸载，绿色免费、支持中文

PowerToys：系统增强工具

  • Color Picker 颜色选择器：Win + Shift + C
  • FancyZones 窗口管理器：Win + ~
  • File Explorer Add-ons：快速预览 SVG 和 Markdown 文件
  • Image Resizer：批量修改图片大小、旋转方向、格式
  • Keyboard Manager：修改键位映射
  • PowerRename：批量重命名，支持正则表达式
  • PowerToys Run 快速启动：Alt + Space
  • 安装文档

效率工具

Cmder：终端神器

  • 便携解压即用，支持子窗口，自带 git、ls 等命令
  • Github

Everything：搜索神器

  • Windows 平台最快的文件搜索软件，支持整词、路经匹配、正则表达式搜索

Wox：效率神器

  • 可搜索安装的程序，支持中文拼音模糊搜索、浏览器书签
  • 可调用 Everything 进行快速全局搜索，支持插件扩展和自定义主题
  • Github

Snipaste：截图神器

  • 免费无广告，自动检测界面元素区域、像素级控制
  • 支持标注(矩形、椭圆、线条、箭头、铅笔、马克笔、文字、马赛克、高斯模糊等)
  • 贴图、取色功能
  • 使用文档

TrafficMonitor：网速监控悬浮窗

  • 显示网络传输速率、CPU 和内存占用率，支持嵌入任务栏、更换皮肤

EarTrumpet：音量管理神器

  • 基于 Microsoft Store 托管的 UWP 应用程序，支持明/暗模式和快捷键设置
  • Microsoft Store

TranslucentTB：任务栏透明

  • 支持亚克力、模糊、透明、主题色、不透明效果，支持自定义颜色
  • Microsoft Store | 汉化版

KeymouseGo：按键精灵

  • 录制鼠标键盘操作进行自动化操作

媒体工具

PotPlayer：视频播放神器

  • 界面简洁可自定义皮肤，功能强大，视频/音频格式支持全面
  • 最新版直链下载

Honeyview：看图神器

  • 支持众多图片格式(含PSD预览)，可批量转换和调整，显示EXIF信息

Wallpaper Engine：壁纸神器

  • 内存占用低，支持视频、网页、2D、3D、GIF 等类型壁纸
  • 创意工坊

ScreenToGif：GIF录制神器

  • 支持屏幕、摄像头、画板录制，可压缩、裁剪、涂鸦、模糊、添加字幕水印等
  • Github

文件工具

bandizip：压缩/解压神器

  • 界面简洁清新，集压缩/解压/浏览/编辑为一体，支持处理乱码
  • 最新版存在广告，需要无广告的可下载 6.x 版本

Duplicate Cleaner：查重神器

  • 快速查找重复文件、支持多目录，灵活的搜索设置
  • 绿色汉化版

WizTree：硬盘分析工具

  • 分析速度极快，可视化显示空间占用，支持数据导出，免费无广告

NeatConverter：电子书格式转换器

  • 完全免费，支持 ePub、Azw3、Mobi、Doc、PDF、TXT 文件的互转

HiBit Uninstaller：卸载神器

  • 强制卸载、批量卸载，安全清理注册表和垃圾文件，快捷方式修复

微信相关

RevokeMsgPatcher：微信/QQ/TIM 防撤回补丁

  • 支持微信/QQ/TIM 防撤回，支持微信多开

CleanMyWechat：微信清理工具

  • 自动识别微信账号，支持自定义路径，同时管理多个账号
  • 自由设置删除的文件类型和时间距离，默认365天

其他工具

12306Bypass：抢票神器

  • 免费可用，全程自动抢票、自动抢候补、自动识别验证码，支持多账号

Umi-OCR：文字识别神器

  • 免费开源，解压即用离线运行，自带高效离线 OCR 引擎
  • 支持命令行、HTTP 接口等多种调用方式，截图/批量 OCR / 二维码 / 数学公式识别
