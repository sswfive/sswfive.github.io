NumPy 概述

NumPy 是 Python 中做科学计算的基础库，也是大部分 Python 科学计算库的基础库。主要用于：

  • 数值计算
  • 大型多维数组（矩阵）的操作和处理

数组和数组的计算（广播机制）

广播规则：如果两个数组的后缘维度（即从末尾开始算起的维度）的轴长度相符或其中一方的长度为1，则认为它们是广播兼容的。广播会在缺失和（或）长度为1的维度上进行。

简单来说，两个数组 shape 得到的元组的后2位要相同，或者后2位中一个相同，另外一个数字有一个数组为1。

参数 解释
frame 文件、字符串或产生器，可以是 .gz 或 .bz2 压缩文件
dtype 数据类型，csv 的字符串以什么数据类型读入数组中，默认 np.float

skiprows 跳过前 X 行，一般跳过第一行表头
usecols 读取指定的列，索引，元组类型
unpack 如果 True，读入属性将分别写入不同数组变量，False 读入数据只写入一个数组变量，默认 False，相当于转置的效果

NumPy 中的 nan 和 inf

nan (NAN, Nan)：not a number，表示不是一个数字。

什么时候会出现 nan：

  • 当我们读取本地的文件为 float 的时候，如果有缺失，就会出现 nan
  • 当做了一个不合适的计算的时候（比如无穷大减去无穷大）

inf (-inf, inf)：infinity，inf 表示正无穷，-inf 表示负无穷。

什么时候会出现 inf：

  • 比如一个数字除以0（Python 中直接会报错，NumPy 中是一个 inf 或 -inf）

inf 和 nan 的 type 类型都是 float

nan 的注意点：

  • 两个 nan 是不相等的，即 np.nan != np.nan
  • 可以利用以上的特性，判断数组中 nan 的个数：np.count_nonzero(t != t)
  • 判断一个数字是否为 nan：np.isnan(a)，返回 bool 类型
  • 把 nan 替换为0：t[np.isnan(t)] = 0
  • nan 和任何值计算都为 nan

NumPy 中常用统计函数

函数 说明
t.sum(axis=None) 求和
t.mean(axis=None) 均值，受离群点的影响较大
np.median(t, axis=None) 中值
t.max(axis=None) 最大值
t.min(axis=None) 最小值
np.ptp(t, axis=None) 极值，即最大值和最小值之差
t.std(axis=None) 标准差

默认返回多维数组的全部统计结果，如果指定 axis 则返回当前轴上的结果。

标准差：是一组数据平均值分散程度的一种度量。标准差越大，代表大部分数值和其平均值之间差异较大，数据波动越大越不稳定；标准差越小，代表这些数值较接近平均值，数据越稳定。

copy 和 view 的区别

  1. a = b：完全不复制，a 和 b 相互影响
  2. a = b[:]：视图操作，会创建新的对象 a，但 a 的数据完全由 b 保管，两者数据变化一致
  3. a = b.copy()：复制，a 和 b 互不影响
